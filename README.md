# SysProg-and-OS-Admin-Labs
This repository was created for laboratory works on the course
"System Programming and OS Administration".

## Repository contents

- `count_files.sh` — Bash script for counting files in a directory (Lab 2)
- `.github/workflows/bash-check.yml` — GitHub Actions workflow for Bash syntax check (Lab 3)
- `lab4/` — RPM package for Lab 4 (spec, man page, config, RPM packages)
- `lab5/` — Debian package for Lab 5, including the Bash script, configuration, packaging files, and the built `.deb` package. Published in Launchpad PPA:
https://launchpad.net/~viktoiiaa/+archive/ubuntu/count-files.

## Usage
./count_files.sh
